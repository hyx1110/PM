# 首页办公屏幕适配说明

## 目标与范围

以公司 1920×1080 显示器的日常阅读为目标，降低信息密度、放大正文，不再将所有首页模块压在同一屏中。只修改首页与首页组件的布局、字号和局部展示状态；左侧导航、顶栏、全局样式和其他业务页面不变。

## 新的模块顺序

1. **顶部概览**：待处理事项、进行中项目、任务完成率、需要关注。待办仍为第一个卡片，保留红色数量提示及悬停浮层。
2. **全宽项目甘特图**：占满首页内容区域。默认折叠任务，仅显示项目摘要；支持逐项目或全部展开/收起。高度由内容决定，没有固定高度或内部纵向滚动；窄窗口横向滚动只发生在甘特图区域，名称与负责人列固定在左侧。
3. **执行与关注**：计划/实际工时对比、需要关注，两列排列；默认各展示 3 条，点击查看更多可展开接口已返回的条目。
4. **趋势与健康度**：工时趋势、项目健康度，两列排列。

卡片留白和间距以 20–24px 为主，主标题 28px、模块标题 20px、主要正文 14–15px、辅助文字 12–13px。增加行高和按钮点击区域，删除重复的装饰性英文小标题。

## 展开与数据边界

- 甘特图首次打开显示项目摘要，用户展开后直接显示接口返回的重点任务；审批刷新时保留已有展开/折叠选择。全部展开仅针对当前展示的项目，不代表下载全系统项目。
- 原后端首页接口仍选取最多 5 个重点项目，每个项目返回最多 6 条任务摘要。本次不修改接口查询量或统计口径；展开项目后明确提示展示数量，并提供“查看项目全部任务”入口，避免把摘要误认为完整任务清单。
- 保留计划/实际工期双条、今天竖线、状态、负责人、真实任务进度；悬停查看日期，点击任务打开详情抽屉。今天及本月判断沿用北京时间工具。
- 待办浮层继续预览最多 7 项，放大至 620px 并限制其内部列表高度，可滚动查看；详情抽屉放大至 560px（不超视口宽度），审批和确认仍调用原业务接口。
- 不增加 mock 数据，不调整工时、任务、项目状态、权限或审批规则；无新增依赖、数据库字段或迁移。

## 窄窗口适配

- 浏览器视口宽度不大于 1500px：四张顶部概览卡变为两列。
- 视口宽度不大于 1440px：下方信息卡片变为单列，保持字号；页头可换行。
- 甘特表格保留 940px 的最小内容宽度，容器不足时局部横向滚动；工时图表保留 620px 最小宽度，不挤压日期字号。
- 判断依据是浏览器 CSS 视口而非显示器标称分辨率；系统显示缩放、浏览器缩放和窗口大小都会影响断点。全系统现有 1180px 最小页面宽度未改变，本次不是移动端整体适配。

## 留给维护者自行查看

以下是手工查看清单，并非已执行的测试结果。本次只编辑源码并静态阅读，未安装、启动、构建、测试或浏览器截图验证。

1. 在公司 1920×1080 屏幕、浏览器正常缩放下，查看顶部字号、甘特图日期和任务名称；再分别按公司实际使用的系统/浏览器缩放查看布局。
2. 逐个展开、全部展开、逐个折叠、全部收起：甘特图高度应随内容改变，下方卡片自然移动，不出现内部纵向滚动条或遮挡。
3. 展开多个项目，审批一条待办刷新首页：仍在返回范围内的项目保留展开状态。
4. 确认项目与任务跳转、任务抽屉、待办审批/预约/加班审批、趋势时间范围切换仍可用。
5. 在任务名很长、多负责人、无数据、待办数量较多时检查换行、浮层滚动和信息提示。
6. 缩窄窗口：概览变两列，下方卡片变单列，图表只在各自容器内横向滚动；字号不随窗口变小。
