# 父任务创建审批说明

本次只修改源码、迁移脚本和文档。未安装依赖，未执行迁移、测试、构建或启动服务；以下操作由维护者自行完成。

## 业务规则

“父任务”按任务层级定义为没有上级任务的顶层任务。新增父任务需要部门主管审批；其下的子任务及更深层子任务不需要逐级重复审批。

| 场景 | 处理方式 |
| --- | --- |
| 新建顶层任务（含 Excel 导入） | 保存为待审批，通知项目所属部门当前设置的部门主管 |
| 部门主管或超级管理员新建顶层任务 | 同样待审批，不因创建者角色而自动通过 |
| 添加子任务 | 父任务及祖先均须审批通过或免单独审批；保存后生效 |
| 未设置有效部门主管 | 明确提示先配置部门及部门主管，不保存新父任务 |
| 纯超级管理员、职能主管、项目经理 | 不拥有父任务审批权 |
| 超级管理员兼部门主管 | 只有同时被设置为项目所属部门负责人时，才可审批该部门任务 |
| 审批通过 | 开放子任务、预约、执行、加班，仍须满足原有成员、日期、工时和预约规则 |
| 审批驳回 | 提供原因；有项目管理权限的用户修改后点击“重新提交” |
| 待审批任务修改 | 不允许，以免审批内容在审核中被替换；可由有删除权限者按原规则删除，或驳回后修改 |
| 已审批任务编辑 | 仅允许有管理权限者修改描述和备注，任务成员仍只能改备注；名称、成员、层级、日期和预计工时锁定，接口也拒绝这些字段 |
| 已完成父任务添加子任务 | 项目尚未确认完成且父任务仍有计划工时额度时允许新增，保存后重新汇总父任务及祖先状态 |

审批是独立维度：`pending` 待审批、`approved` 已通过、`rejected` 已驳回、`not_required` 子任务免单独审批。任务进度仍显示未开始、进行中、已完成、已逾期四种状态。待审批/已驳回任务显示未开始，不产生执行延期提醒，也不进入执行统计、我的可执行任务及项目过程报表。

审批人以处理时项目所属部门的当前负责人为准。人员必须有效、具有部门主管角色，且属于该部门；更换部门主管后新主管从待办/任务列表处理，原主管不能继续审批。待审批通知不等于当前审批授权；任务被删除或审批结束后移除对应待审批通知，结果通知仍保留。

## 操作步骤

1. 项目经理进入“任务管理”或“项目详情 → 项目任务”，在已批准且未完成的项目中新增任务。
2. 不选择父任务即创建顶层任务。填写成员、日期及工时，点击“提交部门主管审批”。
3. 部门主管在“首页 → 待处理事项 → 父任务审批”打开详情并确认/驳回；也可在“任务管理”筛选待审批后点击“审批”。
4. 审批详情展示项目名称、任务名称、项目成员、计划起止日期、预计工时、描述和备注。驳回原因必填。
5. 通过后任务负责人及项目经理收到结果通知；项目经理可添加子任务或预约该任务工时。执行填报仍需满足有效预约或已审批加班等既有规则。
6. 被驳回时，在审批状态上悬停查看意见，编辑修正并保存，然后“重新提交”。每次决定与重新提交均保存操作日志。

## 工时与层级边界

- 所有未删除的顶层任务仍占用项目计划分配额度，包括待审批和已驳回任务，防止并行申请透支。驳回不会自动释放计划额度；不再需要的任务可按原删除规则删除后释放。
- 顶层任务工时之和不能超过项目预算，同级子任务工时之和不能超过父任务预算。审批通过、重新提交时再次校验额度、有效成员和日期范围。
- 已完成子任务仍占用计划分配额度。例如父任务 16h、已完成子任务 8h，仍可新增最多 8h 的子任务；全部额度已分配时拒绝新增。新增后父任务不再维持“已完成”，状态按当前子任务重新汇总。
- 子任务的 `not_required` 表示无需单独审批，未完成时仍按原管理权限与计划校验维护。已完成任务仅允许修改描述/备注；项目确认完成后仍执行原项目封存限制。
- 子任务成员只能从父任务成员选择，日期须包含在父任务和项目周期内。已经完成的父任务不可新增子任务。
- 禁止把子任务提升为顶层任务，或把顶层任务移动成子任务，以免绕过审批。需要改变这类层级时按正确位置新建，旧任务按原安全删除规则处理。
- 待审批/驳回的父任务仍是未完成业务，项目不能在这些任务尚未处理时确认完成。
- Excel 导入应先导入父任务并完成审批，再导入其子任务；不能在同一批次中让未经审批的新父任务直接拥有可执行子任务。子任务导入失败会进入原有导入错误明细。

## 手工验收清单（未执行）

- 新建顶层任务显示待审批，首页部门主管收到待办，普通成员/纯超级管理员没有审批按钮；调用审批接口也不能越权。

- 通过后可以新增子任务及多级子任务，无额外审批；成员/日期/工时限制保持有效。
- 驳回须填写原因，修改后重新提交，上一轮决定留在操作日志；重复通过/重复驳回有明确错误。
- 并发审批、审批与删除、审批与项目资源变更，最终只允许合法状态落库；不重复发送成功通知。
- 导入父任务同样待审批，未审批父任务的子任务导入失败并显示原因。
- 历史任务、已有预约和执行记录继续可用；新待审任务不会误显示为延期执行任务。
