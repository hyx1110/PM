# 项目协同系统用户使用手册

适用对象：项目经理、项目成员及协助审批的部门主管。  
编写依据：截至 2026-10-07 的当前项目工作区代码。  
配套材料：[用户培训 PPT](项目协同系统_用户培训.pptx)。

本手册按项目推进过程讲解操作，不涉及安装或部署。菜单、按钮和可见数据同时受到账号权限、项目归属、任务分配及业务状态约束。示例项目、甲乙丙及示例数字均为教学用例，不是真实业务数据。

## 1. 快速上手

### 项目经理

1. “项目管理”新建项目，指定日期、工时和初始成员，保存并提交部门主管审批。
2. 审批通过后，在“任务管理”或项目详情的“项目任务”拆分任务、分配人员。
3. 在“任务共享看板”预约具体任务的成员时间，等待本人确认。
4. 在首页、任务执行及过程报表跟踪工作；工时、成员或延期变更走项目资源申请。
5. 所有任务和相关申请处理完毕后，手动确认项目完成，再进行项目评价。

### 项目成员

1. 查看首页待处理事项和今日日程。
2. 核对发给自己的预约，选择“本人同意”或“本人拒绝”。
3. 查看分配给自己的任务，也可为本人被分配的末级任务预约本人时间。
4. 实际工作后，在“任务执行”填写本次日期、实际工时、状态和执行说明。
5. 会议、培训、休假等维护个人时间安排；非工作时间工作先申请加班。

**项目审批不等于预约确认；预约工时不等于实际工时；任务完成不等于项目结案。**

## 2. 登录、个人设置与角色边界

### 登录与个人设置

1. 使用管理员提供的系统地址，以“员工号 / 登录账号”和密码登录，不是用姓名登录。
2. 点击右上角姓名或头像，选择“修改登录密码”，填写原密码、新密码和确认密码。
3. “修改个人资料”允许修改姓名、邮箱。员工号不可在此修改；部门、组织、直属主管、角色由管理员维护。
4. 右上角显示账号拥有的多个角色。离开公用电脑前选择“退出登录”。

账号被禁用或忘记密码时联系管理员。反馈问题不要附带密码。

| 身份 | 可见范围 | 常用操作边界 |
| --- | --- | --- |
| 项目经理 | 自己负责或参与的项目及相关任务 | 维护自己负责的项目；仅参与的项目通常只读；可看负责项目下成员执行记录，但不能仅凭项目经理身份修改他人记录 |
| 项目成员 | 自己参与项目及相关任务 | 维护本人任务备注、预约和执行记录；不能调整任务核心计划或项目预算 |
| 职能主管 | 本人及递归直属下属相关项目、任务和日程 | 本人负责项目可维护，其他可见项目不等于可管理 |
| 部门主管 | 管理模块中的全局项目、任务和日程 | 处理本人所负责部门的项目审批及资源审批，并有相应全局业务管理权限 |
| 超级管理员 | 全局业务及系统管理数据 | 管理用户、组织、权限等；首次项目审批仍按所属部门主管规则执行 |

一个账号可有多个角色。拥有“项目经理”角色不等于负责所有项目。按钮不存在时，先核对归属、审批状态和项目是否已经完成。

首页甘特图单独按关系范围展示：本人及全部层级直属下属相关的已审批项目，不是管理模块的全量项目目录。需要进一步查找时进入“项目管理”。

## 3. 首页怎么用

| 位置 | 内容 | 建议操作 |
| --- | --- | --- |
| 顶部概览 | 待处理事项、进行中项目、任务完成率、需要关注 | 先看待办和异常 |
| 第二行 | 待处理事项、我的今日日程、需要关注 | 打开预约或审批详情，核对当天安排 |
| 第三行 | 项目健康度、项目进度甘特图 | 展开项目查看关键任务，悬停查看时间信息，点击任务打开详情 |
| 第四行 | 计划与实际、工时趋势 | 对照工时偏差，切换统计时间范围 |

待处理事项整合审批、预约和我的任务，可切换分类。具有相应资格时，可在详情中批准、驳回或确认预约。驳回、拒绝请填写明确原因。

甘特图在首页用于查看，不用于直接改期。首页只预览部分任务时，进入项目详情查看完整任务。待办和任务的预览数量也不能代替完整分页查询。

## 4. 四种工时不要混淆

| 名称 | 含义 | 来源 |
| --- | --- | --- |
| 项目总工时 | 经审批的项目计划额度 | 创建项目填写，后续增加走资源申请 |
| 任务计划工时 / 预计工时 | 分给任务的额度，多名任务成员共享 | 项目负责人分配 |
| 预约工时 | 给具体人员安排的工作时段 | 按时间自动计算；待确认也预占任务和项目额度 |
| 实际工时 | 真正发生且已填报的工作量 | 有效执行记录累计，含已填报加班 |

新建项目默认工时按“工作日数 × 有效成员数 × 8h”估算，项目经理计入且去重。新建任务按工作日数和所选任务成员数估算。默认值是计划建议，不是实际投入，可按真实工作量手动调整。

例如任务计划 8h，甲、乙各预约 2h，共占用 4h，不是每人都拥有 8h。实际分别填报 1.5h、2h，累计实际为 3.5h，不会用预约的 4h 代替。

## 5. 项目经理：创建项目与审批

入口：**项目管理 → 新建项目**。

1. 填写项目名称，编号保存后自动生成。
2. 核对项目经理、所属部门。普通项目经理以本人为负责人。
3. 选择初始成员，可按部门、组织逐级多选。表单要求至少选择一名初始成员，项目经理自动纳入项目。
4. 填写计划开始、计划结束日期，结束不能早于开始。
5. 等待默认工时计算，核对“项目总工时”，按真实计划调整。
6. 填写描述、备注。
7. 未准备好点击“保存草稿”；准备好点击“保存并提交审批”。已有草稿也可在列表点击“提交审批”。

查看列表“审批”列。只有“已审批”的项目才可正常新增任务、预约和执行。全部角色创建项目均需所属部门主管审批，不自动通过。

提示未配置部门主管时，请管理员核对部门负责人设置，不要换无关部门绕过审批。被驳回时查看原因，修改后重新提交。

两组状态含义不同：

- 审批状态：草稿、待部门主管审批、已审批、已驳回。
- 业务状态：未开始、进行中、已完成、已逾期。

“已审批”不是“已完成”。“已逾期”表示计划结束已过但工作未完成，不是项目被取消。

## 6. 项目经理：创建任务与多级子任务

入口：**任务管理 → 新增任务**，或 **项目管理 → 项目名称 → 项目任务 → 新增任务**。

1. 先选已审批、有权管理的项目，查看项目计划周期。
2. 填任务名称，需要分解时选父任务。
3. “项目成员”可多选。顶级任务只能选有效项目成员，子任务只能选父任务已指定的成员。
4. 按天填计划日期，任务不得超出项目，子任务不得超出父任务。
5. 核对“任务计划工时”，必须为正数且按 0.5h 计，例如 0.5、1、1.5h，不接受 0.3h。
6. 填描述、备注并保存。

### 层级与额度规则

- 顶级任务预计工时合计不得超过项目总工时。
- 同一父任务的直接子任务预计工时合计不得超过父任务工时。
- 支持多级子任务。有子任务的任务是汇总层，后续预约和执行应落在最末级任务。
- 未完成任务可以按规则加子任务，包括进行中任务；已有加班、预约和执行等关联数据可能触发保护，按提示处理，不要随意删除历史。
- 修改成员、日期和工时，不能破坏已有子任务及预约关联。

示例：项目 80h，顶级“开发”48h、“联调”32h。“开发”下拆“接口”24h、“页面”24h。项目分配合计仍为 80h，不重复叠加父子任务。

列表按项目合并名称，任务可展开、折叠。末级任务状态取最新有效执行记录，父任务由子任务汇总。统一显示未开始、进行中、已完成、已逾期，不需要多个页面重复改状态。

## 7. 预约具体任务的工作时间

入口：**任务共享看板 → 预约人力**。

1. 选已审批、未完成且有预约权限的项目。
2. 选具体末级任务，核对计划周期、计划工时和剩余额度。
3. 选该任务已指定的有效成员。找不到人员先核对项目成员和任务分配。
4. 选工作日期、上午或下午、开始及结束时间。时间必须在项目及任务计划范围内。
5. 检查自动计算工时、填写备注，点击“预约”。

直接点击日历某人的空白处会带入人员。点击本人时段可选择“预约项目工时”或个人时间安排。

### 时间限制

- 系统按北京时间处理。
- 正常预约时段为 **08:30–12:00、13:00–17:30**，按 0.5h 选择。
- 上午、下午分开预约，不把午休算入连续工作时段。
- 只能预约未来工作时段，不能预约过去或已开始时段、法定假日或其他非工作日。
- 调休和假日依赖系统工作日历配置，不会自动联网补全。识别不正确时联系管理员。
- 已确认工作安排、休假、会议等个人占用会阻止冲突预约。

### 批量预约

“批量预约”先选项目和任务，再选任务成员，最后选日期、时段。总占用 = 单人工时 × 人数。两人各 1h，共需 2h。待确认也占额度，不要重复提交扩大任务可用工时。

## 8. 确认、拒绝、改期与撤回

从首页待处理事项打开预约，或点击看板预约条打开“预约详情”，核对项目、任务、发起人、人员及时段。

- 能履约：点击“本人同意”。
- 不能履约：点击“本人拒绝”，说明原因。
- 自己为本人被分配任务预约时间：系统自动确认，无需再次自审。

### 多个待确认预约

待确认申请不公开占用人员时段，其他项目可以提出同一时段的竞争预约。普通项目经理看不到其他人发出的灰色未确认预约；发起人和被预约人可查看自己的相关申请，管理权限仍按系统范围控制。

每条申请仍预占所属任务和项目工时。成员接受其中一条后，系统检查冲突，并拒绝重叠的竞争待确认预约。已确认工作安排对有权查看该人员日程的人可见。已拒绝、撤回或取消的条目不继续作为有效日程展示，可在历史预约列表追溯。

请及时确认。到预约结束仍未确认的申请，系统会自动取消并通知相关人员，不能作为执行凭证。已确认预约随时间显示“进行中 / 已完成”，仅表示预约时段的进展，不等于任务已经完成，也不会自动生成实际工时。

| 情况 | 操作与限制 |
| --- | --- |
| 本人发出的待确认预约不再需要 | 详情中“撤回预约” |
| 本人已确认预约需要撤回 | “我的项目预约”或详情撤回；须尚未开始、项目未完成，且预约日期无关联本人正常执行记录 |
| 有维护权限，希望改期 | 编辑预约，或按住预约条中间拖到有效时段；不能通过拖动换人 |
| 为他人调整预约 | 对方需重新确认，改期成功不代表对方已接受 |
| 已开始、已执行或项目已结束 | 不能按普通撤回处理，先联系负责人核对业务记录 |

撤回释放预约对应的时段和额度，不会增加项目批准预算。

## 9. 维护个人会议、培训、休假等安排

入口：**任务共享看板 → 我的时间安排 → 新增安排**。

选择类型，填写起止时间及说明，保存。生效中个人安排占用本人时间，其他人不能重复预约。安排取消后，在列表或详情点击“撤回”，释放占用。

个人安排只是本系统的时间占用，不等于公司 HR 请假审批，也不会自动计入项目实际工时。与已有工作冲突时，先协调原预约，不要用个人安排覆盖已有承诺。

## 10. 项目成员：填报执行记录

入口：**任务执行 → 执行记录 → 填写执行记录**。也可以从任务列表“执行记录”进入。

### 前置条件

- 项目已审批，未完成且未进入评价锁定阶段。
- 自己是这个末级任务的有效成员。
- 所选实际日期范围内，有本人同任务的已确认、进行中或已完成普通预约，待确认不算。
- 工作已经发生，实际日期不能晚于今天。

### 填写步骤

1. 选任务，核对任务预计工时。
2. 选“进行中”或“已完成”，不提供“暂停”。
3. 按天填实际开始及结束日期，结束不早于开始。
4. 填**本次新增**工时，正数且以 0.5h 为单位。
5. 填执行说明，例如“完成接口参数校验，重试逻辑待处理”。
6. 保存后核对列表。任务状态及关联页面的实际工时会同步更新。

已完成记录必须填实际结束日期、实际工时。进行中可以留空工时按工作日容量自动计算，但为避免误将全天容量作为真实投入，**建议明确填写真实工时**。普通执行不能超过所选工作日容量，加班另走申请。

### 避免重复累计

上午已填 2h，下午新增工作 1.5h，第二条应填 **1.5h**，累计 3.5h，不要第二条再填 3.5h。修正原记录使用“编辑”，不是新增相同记录。

状态取最新有效记录，工时累计有效记录；删除最新记录可能回退任务状态。多人承担同一任务时，先核对其他成员是否完成工作和填报，再标“已完成”。已完成任务不能继续新增普通执行记录。

列表“预计 / 实际工时”是任务预计和任务累计实际，不是每行单条记录的工时。修改或删除记录必须符合本人权限和项目未锁定等要求。项目经理能查看成员记录，不代表能代改。

## 11. 申请加班与填报加班执行

入口：**任务执行 → 加班申请 → 我的申请**。

1. 选本人参与、已审批且未完成项目中的本人末级任务。
2. 选任务计划内未来非工作时段，填原因，按 0.5h 计。跨日申请按零点拆分。
3. 等待指定审批人在加班开始前批准。
4. 加班结束后，在批准申请点击“填报执行”，填真实工时和说明。

| 场景 | 审批人 |
| --- | --- |
| 成员申请加班 | 对应项目经理 |
| 项目经理在自己负责项目加班 | 项目所属部门主管 |
| 项目经理在参与但不负责的项目加班 | 该项目经理 |

不允许自己审批自己，配置无效或审批人仍为本人时联系管理员。

加班不显示在普通预约看板，不占普通预约额度，不自动增加项目预算。**批准工时不是实际工时，填报后才计入实际。** 实际加班不得超过批准工时，一条申请仅有一条有效执行记录。正常与加班分开填，禁止重复计入。

申请人可撤回待审批或已批准但未填报申请。填报后先按执行权限处理相关记录。存在待审批或未填报加班时，不能直接将任务或项目结案。

## 12. 项目资源申请、延期和撤回

入口：**项目管理 → 项目名称 → 项目资源申请**，历史列表在“资源申请”页签。

| 变化 | 处理 |
| --- | --- |
| 名称、描述等基本信息 | 有权限时编辑项目，通常不走资源审批 |
| 增加总工时 | 资源申请填写追加量、原因 |
| 添加、移除成员 | 资源申请选择人员，可不追加工时 |
| 逾期项目延长结束日期 | 资源申请填新日期、正数追加工时、原因 |

同张申请可以组合上述资源变化，批准后统一生效。添加人员按部门、组织多选，审批详情显示具体姓名及工号。项目经理不能移除，有任务、预约、加班等依赖的成员先处理关联数据。

提交不等于生效。项目列表提示待审批数量，部门主管首页出现待办，等待所属部门主管批准。

### 延期口径

当前延期入口适用于已审批、未完成且已逾期项目。新结束日必须晚于旧结束日且不早于今天。

系统默认估算：**旧结束日次日起至新结束日的工作日数 × 变更后的有效成员数 × 8h**。项目经理计入人数且去重。这里填写的是追加量，不是原项目总额。可以手动调整，延期必填正数，按 0.5h 计。

等待自动估算完成，或明确手填后提交。审批成功才更新结束日期和预算；任务计划日期需按实际需要另行维护，不要假定项目延期会自动延长每个任务。

### 申请填错

“资源申请”列表中，对本人发起且仍待审批的申请点击“撤回”，再重新提交正确内容。不能撤回他人或已审批申请。撤回不改变现有预算、成员和日期；批准后再调整，应走新的资源变更流程。

## 13. 跟踪进度、报表与项目收尾

### 日常检查

项目经理查看首页逾期和工时偏差，打开甘特图任务详情，在“任务执行”选择项目、任务、人员以及“今天 / 本周 / 本月”查看执行说明。

首页趋势“计划”来自有效普通预约，“实际”来自执行记录并含已填报加班，不是项目预算与实际的直接比较。当前实际趋势按执行记录的“实际开始日期”归集工时，跨日记录也集中计入开始日，不会平均分摊到每天。核对数字时保持项目、人员及统计日期范围一致。

有权限时进入“项目过程报表”，按项目等条件查询，展开任务层级，比较计划工期、实际工期、预计及实际工时。默认项目成员没有该报表和导出权限，可通过任务、首页和自己的执行记录查看。

有导出权限时，从“数据导入导出”选择授权的导出项和筛选范围，不可导出超出自己权限的数据。

### 手动完成与评价

1. 核对所有任务完成，工时真实，待审批或未填报加班等事项已经处理。
2. 全部任务完成只提示，不会自动结束项目。还需补任务时暂不结案。
3. 项目列表点击“确认完成”，或详情点击“确认项目完成”。
4. 项目成为已完成，后续新增任务、预约及修改执行记录等受锁定。
5. “项目过程报表”点击“评价项目”，填写评价表单，点击“保存评价”。

评价只针对项目，不逐任务评价，每个项目仅一次，保存后显示“已完成评价”。项目负责人评价本人项目，部门主管和超级管理员保留相应权限。提交前认真核对，不把评价当临时草稿。

## 14. 查询和通知

### 多选筛选

部门 / 组织 / 人员级联支持多选，可同时选不同部门或多人，也可按姓名、工号搜索。查询只收窄权限，不扩大可见范围。项目管理级联筛选标注“项目经理”，按负责人维度筛选，不是所有项目参与人。

人员通常按工号排序，共享看板本人优先。看板按范围显示人员整行，找不到人先清空筛选，再核对权限和成员关系。

### 站内通知与公司邮件

点击右上角铃铛查看通知，核对人名、项目、任务、时段和结果。**标记已读不会接受预约或批准申请。** 从首页待办或业务详情正式处理，历史通知是否还有效以最新业务状态为准。

公司启用邮件功能、账号邮箱配置正确后，相关通知可发到公司邮箱。普通用户不配置 SMTP。未收到邮件先看站内通知和个人邮箱，再联系管理员，不应依赖邮件作为唯一待办入口。

## 15. 常见问题

| 现象 | 优先检查与处理 |
| --- | --- |
| 找不到项目或任务 | 清除筛选，确认项目成员、任务分配及权限 |
| 能看不能编辑 | 是否仅为成员、是否待审批或已完成；请负责人维护 |
| 新增任务找不到项目 | 先完成项目审批，选择有管理权限且未结束项目 |
| 预约找不到人员 | 先通过资源申请成为有效成员，再分配到具体任务 |
| 工时不足 | 核对任务和项目额度、待确认预占、人数乘时长；撤回无用预约或申请资源 |
| 时段不可选 | 检查是否过去、午休、非工作日、个人安排或确认冲突 |
| 执行保存失败 | 本人末级任务、有效预约、非未来日期、0.5h 单位；加班需已批准凭证 |
| 已完成记录提示必填 | 补实际结束日期和本次实际工时 |
| 任务全完成项目未完成 | 负责人核对收尾后手动确认项目完成 |
| 延期无法提交 | 符合逾期入口条件，新日期、正数追加量、原因都有效 |
| 资源申请无法撤回 | 仅本人发起、仍待审批可撤回 |
| 首页和列表数字不同 | 比较关系范围、时间窗和预览范围，完整数据看业务列表 |
| 通知已读但待办仍在 | 已读不是办理，进入详情正式操作 |

反馈问题请提供角色、项目/任务名称、发生时间、步骤、完整错误提示及脱敏截图，不要提供密码。

## 16. 培训演练与每日清单

仅在获得授权的测试环境执行，不在正式业务数据上试操作。

1. 分配虚构角色：经理甲、成员乙、部门主管丙，建立“培训演练项目”。
2. 选未来工作日期，项目工时手动设 16h，指定乙为初始成员，由丙审批。
3. 甲创建末级任务“接口联调”，计划 4h，分配乙。
4. 甲预约乙某未来工作日 09:00–10:00，乙从首页确认。
5. 实际工作发生后，乙填报本次 1h。不要填写未来实际日期。
6. 实际工作和填报都结束后，任务标完成，甲手动完成项目并评价。
7. 另外使用未结案演练项目练习资源申请撤回、个人安排撤回及加班流程。

| 项目经理每日检查 | 项目成员每日检查 |
| --- | --- |
| 待办、逾期、工时偏差 | 待办、本人任务、今日日程 |
| 任务分配与预约确认 | 及时确认或拒绝并说明原因 |
| 成员执行说明与累计实际工时 | 填本次真实工时，不重复填累计量 |
| 资源变化先审批 | 时间安排变化及时协调、撤回 |
| 核对后手动结案、评价 | 加班先申请、审批后工作与填报 |
