# V2.0 范围与维护者验收清单

## 当前交付范围

| 领域 | V2.0 规则 |
| --- | --- |
| 首页 | 我的任务、本人预约待办、项目/资源审批、近 14 天与本月计划工时；按登录账号权限范围统计 |
| 项目 | 编号自动生成；所有项目由部门主管审批；工时和成员增删统一走项目资源申请；全部任务完成后手动确认项目完成 |
| 任务 | 任意层级、多项目成员；子任务成员继承父任务范围；父子/项目工时约束；最新执行记录驱动三种持久化状态，逾期动态计算 |
| 项目状态 | 未开始、进行中、已完成三种持久化状态；已逾期按计划结束日期动态计算；审批状态独立维护 |
| 权限 | 超管/部门主管全量；职能主管为本人及全部下属相关数据；项目经理/成员为本人负责、参与或承担任务的数据 |
| 共享看板 | 待确认预约仅申请人和被预约人可见且不占用；确认后才占用时间/额度，并关闭同时间其他提案 |
| 个人时间 | 培训、会议、休假、外出、出差等本人安排与撤回；有效安排阻止重叠预约 |
| 项目审批 | 所有项目和项目资源申请提交给项目所属部门主管，不自动通过 |
| 过程评价 | 项目完成后，由项目负责人、部门主管或超管对整个项目一次性评价；不再逐任务评价 |
| 用户 | 员工号登录、姓名、邮箱、部门、组织、直属主管、系统角色；新增必须设置部门和直属主管 |
| 数据交换 | 用户/项目/任务导入，排期/执行/过程报表按权限范围及项目、人员、组织筛选导出 |
| 后台能力 | Redis/Celery、人员负载、风险扫描、工作日历保留；负载、风险、日历 UI 隐藏 |

不包含正式 HRDB 连接器、真实数据导入、AI 排期/预测、移动 App、通用审批引擎和 Kubernetes。

## 维护者自行验收

本次源码交付未安装依赖、未执行迁移、未构建、未运行测试、未启动服务。以下仅供维护者后续验收。

### 数据库与角色

- [ ] 备份数据库后执行到 `20260921_0014`，再运行初始化脚本。
- [ ] 新用户必须选择部门和直属主管；未选角色时自动获得项目成员。
- [ ] 选择项目成员角色不会发生重复关联或 `database operation failed`。
- [ ] 超级管理员只能由初始化脚本配置，页面不能新增或移除。
- [ ] 默认权限与 `ROLE_PERMISSION_GUIDE.md` 一致，普通项目成员没有 `project:edit`。

### 项目和任务数据范围

- [ ] 超管/部门主管可查看和管理全部项目、任务。
- [ ] 职能主管可查看本人和全部层级下属相关项目、任务；仅本人负责项目可维护。
- [ ] 项目经理可查看本人负责或参与项目；仅本人负责项目可维护成员和任务。
- [ ] 项目成员只能查看本人参与或负责任务相关项目，不能维护项目核心数据。
- [ ] 项目负责人能看到所负责项目的全部任务，即使本人不是该任务的项目成员。
- [ ] 姓名/工号共用一个查询框，部门/组织共用一个查询框。

### 执行与完成状态

- [ ] 同一任务允许多条执行记录，任务状态取最新一条未删除记录。
- [ ] 更新较早记录不会覆盖较新的状态；删除最新记录后正确回退。
- [ ] 父任务由子任务状态汇总，项目运行态随任务状态变化。
- [ ] 所有任务完成后项目不自动关闭，列表提示项目负责人“确认完成”。
- [ ] 只有项目负责人、部门主管或超管在依赖清理完毕后可确认项目完成。
- [ ] 实际日期不能晚于北京时间当天，实际工时不得超过所选工作日容量。

### 预约和日程

- [ ] 部门主管/超管可看全部人员；职能主管可看本人及全部下属；项目经理可看本人项目成员；普通成员仅本人。
- [ ] 看板筛选后不匹配人员整行消失。
- [ ] 同项目使用稳定颜色，待确认/变更预约为灰色，拒绝预约不显示。
- [ ] 项目负责人预约自己的项目任务工时后直接为已确认，不出现自己审批自己。
- [ ] 预约其他成员仍进入本人待确认，由被预约人同意或拒绝，确认前提交人可撤回。
- [ ] 有效个人安排与项目预约双向冲突；个人安排可由本人撤回。
- [ ] 只允许工作日 `08:30-12:00`、`13:00-17:30` 的 30 分钟时间粒度，法定节假日不可预约。

### 报表、导出与首页

- [ ] 过程报表按当前账号可见项目展示；已评价行显示“已完成评价”且不能重复评价。
- [ ] 评价只允许项目负责人、部门主管或超管，并要求项目和任务均已完成。
- [ ] 导出按同一数据范围过滤，并支持项目、姓名/工号、部门/组织条件。
- [ ] “近 14 天计划工时”为北京时间今天及此前 13 天确认/进行中/已完成预约之和。
- [ ] “本月计划工时”为当前自然月相同状态预约之和；两项不含待确认、拒绝、撤回、取消和个人安排。
- [ ] 项目经理范围为本人负责/参与/承担任务的项目；职能主管加上所有下属相关项目；部门主管/超管为全部项目。

### 回归

- [ ] 登录错误、用户禁用提示清晰；中文姓名可用，员工号只允许 ASCII。
- [ ] 右上角通知已读后角标立即刷新。
- [ ] 组织树展示人员；操作日志展示字段变化并按北京时间小时归档。
- [ ] 个人资料和密码修改可用，通知偏好入口不存在。
