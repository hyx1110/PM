# V2.0 范围与维护者验收清单

## 交付范围

| 领域 | V2.0 交付 |
|---|---|
| 驾驶舱 | 项目总数/进行/完成/延期、任务完成率、本人预约待办及快捷审批、风险、周工时、14 日趋势 |
| 负载分析 | 日/周/月、人员可用与计划工时、利用率、空闲/超负载、项目占比 |
| 风险中心 | 人力冲突、负载超限、任务延期、项目延期、久未更新、指纹去重、处理闭环 |
| 通知 | 站内通知、已读、偏好、临期任务、邮件/企微/钉钉适配 |
| Excel | 用户/项目/任务模板与导入、导入错误留档、排期/执行/过程报表导出 |
| 共享看板 | 日/周/月、本人培训/会议/休假/出差等个人安排与撤回、点击人员查看全部项目安排、时间点刻度、工作/非工作/法定节假日配色、拖动改期、版本冲突、批量排期、复制上周 |
| 分析报表 | 计划实际、兑现率、项目延期率、任务完成率、成员达成、项目人力占比 |
| 后台任务 | Redis/Celery Worker/Beat、周期风险、临期提醒、外部通知 |
| 项目审批 | 普通项目经理提交给本人直属主管审批；L3/超级管理员创建自动通过；驳回后可修改重提 |
| 工时额度 | 预约占用项目额度、额度不足拦截、项目经理申请追加、L3 审批 |
| 预约审批 | 直接提交、仅被预约人本人审批、确认前由原提交人撤回 |
| 工作日历 | 上午/下午工作段、半小时自动计算、工作日与法定节假日限制、L3 维护 |
| 正式人员架构 | 数字用户主键、员工号登录、一对一人员档案、唯一岗位、部门/组织/直属上级关系、人事职级与系统角色分离 |
| 角色来源 | 五类系统功能角色完整保留；正式 Department Manager/Management Manager 分别自动授予系统 L3/L4，人工与自动来源并存 |
| 成员与主数据 | 无显式角色时默认项目成员；正式接入后 HRDB 人员档案、部门、组织、岗位和直属主管只读同步 |

## 不在本版本

- MES、EES、YES 或其他制造系统实时接口。
- AI 自动排期、AI 风险预测和智能资源推荐。
- 移动 App、通用可配置审批引擎、Kafka、Elasticsearch、Kubernetes；本版只包含“项目/直属主管”和“追加工时/项目所属部门 L3”两条固定审批流。
- 企业微信/钉钉应用级 OAuth；当前为可配置机器人 Webhook。
- 历史评价多版本表；评价变更仍由操作日志追溯。

## 维护者验收建议

本清单只用于维护者自行安装、测试和验收；本次源码交付未执行。

### 升级与权限

- [ ] 从 V1 数据库执行 `alembic upgrade head` 后原有数据完整。
- [ ] 重复执行 `python -m scripts.init_data` 不产生重复权限、角色或管理员。
- [ ] 五类角色获得文档约定的 V2 默认权限，超范围接口返回 403。
- [ ] 现有用户升级后 `employee_no` 与兼容 `username` 相同，仍使用原员工号登录，内部数字主键和历史外键不变。
- [ ] 新增用户必须使用 ASCII 员工号，中文姓名仍可保存；一个用户只有一条人员档案，一个非空 `position_id` 不能同时属于多名员工。
- [ ] 人事 `department_manager` 自动授予系统 L3，人事 `management_manager` 自动授予系统 L4；普通员工不自动获得管理系统角色。
- [ ] 超级管理员、L3、L4、项目经理、项目成员的原有权限功能全部保留，人工授权不受人事职级变更影响。
- [ ] 同一 L3/L4 同时具备人工和职级自动来源时，界面显示“两者并存”；取消人事经理职级后仅自动来源消失，人工角色继续有效。
- [ ] 新用户未显式选择角色时默认获得项目成员，升级前没有角色的历史用户也被补齐项目成员。
- [ ] `data_source=hrdb` 的人员档案、部门与组织在接口和页面中只读；本地测试数据仍可维护。
- [ ] 项目经理在本人负责项目中拥有团队数据范围；在其他项目仅作为成员时，任务、执行、风险和报表不会扩大为团队范围。
- [ ] 普通项目成员的完整任务管理菜单被“我的任务”替代，任务、日程、预约、执行和风险查询均不能返回他人数据。

### 看板

- [ ] 任意登录用户都可创建本人的培训、会议、休假、外出、出差或其他安排，不能替其他用户创建；本人可撤回生效中的安排，已撤回记录保留历史且时段重新开放。
- [ ] 生效中的个人安排在日/周/月看板按类型显示；项目经理、L3、L4 或管理员均不能在重叠时段为该用户新增或调整项目预约。
- [ ] 个人安排与已有 `pending/confirmed/changed/running` 项目预约重叠时创建失败；与本人其他生效个人安排重叠时同样失败并返回 `40901` 冲突明细。
- [ ] 点击人员姓名可查看该人员跨日期、跨项目的全部可见预约，不受当前看板日期和项目筛选影响，并支持分页及单条详情。
- [ ] 项目经理的人员列表只包含本人及自己负责项目的当前成员；L3 包含全部有效人员；L4 包含本人及直属下属；普通成员只包含本人。
- [ ] 项目经理只能预约本人负责项目的有效成员；L3/L4 只能预约直属下属，且下属仍必须是所选项目的有效成员；越权请求由后端返回 403。
- [ ] 被预约人登录后，驾驶舱仅展示预约到本人的 `pending/changed` 待办，并可直接确认或填写原因拒绝。
- [ ] 日/周时间表把时间显示在边界刻度线上；正常工作时间保持白色，午休和上下班边界使用灰色禁用背景，法定节假日整天使用红色系且不可点击或拖入。
- [ ] 新建预约点击“预约”后直接成为 `pending`，不产生草稿。
- [ ] 预约 A 后，仅 A 可以确认或拒绝；项目经理、L3、L4、超级管理员代批均返回 403。
- [ ] `pending/changed` 预约可由原提交人在本人确认前撤回，撤回后释放项目额度；已确认记录不能撤回。
- [ ] 只接受同一天、30 分钟粒度、`08:30-12:00` 或 `13:00-17:30` 内的时段，跨午休和非工作日均被拒绝。
- [ ] 工作日历 `holiday` 日期不可预约，调休周末 `workday` 日期可预约。
- [ ] 驾驶舱周容量和日/周/月负载报表使用相同工作日历，节假日不计可用工时，调休工作日计入。
- [ ] 日、周、月切换与日期范围加载一致。
- [ ] 合法拖动更新开始/结束和工时，已确认记录变为 `changed`。
- [ ] 使用旧版本号拖动返回 `40903`。
- [ ] 批量排期任一人员冲突时整批不创建，并返回全部冲突。
- [ ] 复制上周直接提交待本人审批、写入来源 ID，无效日期/冲突/额度不足记录出现在 `skipped`。

### 项目与工时审批

- [ ] 普通项目经理未配置有效直属主管时不能提交项目，并提示先维护直属主管关系。
- [ ] 非项目经理或替其他经理创建项目时返回 403；普通项目经理合法提交后状态为待直属主管审批。
- [ ] 只有项目中锁定的 `approver_id` 本人能批准/驳回普通项目经理提交的项目，L3、L4 和超级管理员不能代批。
- [ ] L3 或超级管理员创建项目时直接进入已审批的计划状态，不产生待自己审批的记录。
- [ ] 创建项目未选择普通成员时校验失败；选择成员后，项目经理与所选成员在同一事务写入成员表，项目经理显示为固定成员且不能移除。
- [ ] 项目审批前不能添加成员、创建任务或预约人力。
- [ ] 预约累计工时超过项目额度时整笔拒绝，不出现并发超额。
- [ ] 项目经理提交追加工时后，仅对应 L3 能审批；批准后项目总额度正确增加。
- [ ] 角色页面、顶栏和组织页面统一显示 L3/L4，不再把代码直接展示给用户。

### 风险

- [ ] 构造五类风险后手动扫描可生成记录。
- [ ] 重复扫描刷新同一指纹，不新增重复记录。
- [ ] 风险可进入处理中、解决、忽略，处理人/时间/说明完整。
- [ ] 非授权用户不能查看或处理范围外项目风险。

### 通知与任务

- [ ] 新增/提交/变更/确认/拒绝排期生成预期站内通知。
- [ ] 未读数、单条已读、全部已读和偏好更新有效。
- [ ] Worker/Beat 运行后按用户提前小时生成临期提醒。
- [ ] 分别配置 SMTP、企业微信、钉钉后验证成功通道写入 `delivered_channels`。
- [ ] 外部渠道故障不回滚排期、风险和站内通知事务。

### Excel

- [ ] 三类模板可下载并正常打开，标题冻结、筛选、说明和下拉有效。
- [ ] 项目导入模板必须填写项目成员员工号，支持逗号分隔多名成员，并拒绝缺失员工号、重复填写项目经理或无效组织关系。
- [ ] 日期与工时以真实单元格类型填写时导入成功。
- [ ] 错误员工号、重复岗位编号、项目编号、日期和枚举显示准确 Excel 行号与原因。
- [ ] 部分成功导入时，成功/失败/总数和错误明细一致。
- [ ] 三类导出仅包含当前用户数据范围，日期/数字可在 Excel 中参与计算。

### 报表与回归

- [ ] 驾驶舱指标与明细查询抽样一致。
- [ ] 负载日/周/月聚合、空闲/超负载和项目占比正确。
- [ ] 软删除项目、任务、执行记录不进入正常页面与报表，项目经理在非本人负责项目中只能看到自己的任务和执行记录。
- [ ] 经营报表计划/实际、延期率、成员达成和人力占比正确。
- [ ] 员工号登录、用户、组织、五类系统角色、项目、任务、排期状态机、执行、评价、日志无回归。
