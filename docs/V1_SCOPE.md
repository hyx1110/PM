# V1.0 范围与验收清单

## 已纳入范围

- [x] 登录、退出、JWT 鉴权、账号禁用。
- [x] 用户新增、编辑、查询、启用、禁用、角色分配。
- [x] 部门、L1-L4 组织树、主管和用户归属。
- [x] 五类默认角色、权限列表、角色权限配置。
- [x] 项目增查改、草稿逻辑删除、项目状态、经理、周期。
- [x] 项目成员添加、查看、移除、投入比例和历史关系。
- [x] 一级和二级任务、负责人、计划时间、预计工时、状态。
- [x] 人员 × 时间轴的日/周共享看板，最小 1 小时表头粒度。
- [x] Project、Routine、Training、Leave、Other 视觉区分。
- [x] 人力预约新增、修改、删除草稿、提交确认。
- [x] 预约同意、拒绝、修改后重新确认。
- [x] 同一人员时间交集检测和完整冲突列表。
- [x] 实际开始、实际结束、实际工时、说明和异常填报。
- [x] 项目过程报表、预计/实际人力、达成率和达成质量。
- [x] 动态延期状态和 `confirmed/running` 人员日负载。
- [x] 关键操作、共享看板修改前后数据留痕。

## 明确不纳入范围

- Redis、Kafka、Elasticsearch、Kubernetes。
- AI 自动排期、AI 风险预测、自动推荐。
- MES、EES、YES 实时集成。
- 移动 App、多租户、复杂审批流和消息中心。
- 看板拖拽、批量排期、复制上周计划、复杂甘特图。
- Excel 导入导出和复杂图表分析。
- Celery 或其他后台定时任务。

## 维护者验收顺序

1. 执行首版数据库迁移和初始化脚本，确认默认角色、权限、管理员存在。
2. 使用初始管理员登录，确认 `/auth/me` 返回角色和权限。
3. 建立部门、组织、项目经理和项目成员账号。
4. 创建项目、添加成员、创建一级与二级任务。
5. 在共享看板空白小时创建预约草稿并提交。
6. 使用预约成员账号确认或拒绝预约。
7. 创建相同人员的重叠有效预约，确认返回 HTTP 409 和全部冲突详情；验证 12:00 结束与 12:00 开始不冲突。
8. 修改已确认预约，确认状态变为 `changed` 并要求重新确认。
9. 使用成员账号填写实际执行时间和工时。
10. 查看过程报表，核对一级/二级任务、计划/实际和工时聚合。
11. 使用项目经理录入 0-100 的达成率和达成质量。
12. 查看人员负载，确认超过每日标准工时标记为过载。
13. 查看操作日志，确认项目、成员、任务、预约、执行和评价的前后数据可追溯。
14. 分别使用五类角色验证页面权限、API 权限和项目数据范围。
