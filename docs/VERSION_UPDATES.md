## 2026-10-10｜界面体验与首页布局更新

### 本次范围

以已上传提交 `136df0f`（日程权限、立项报告必传及项目日期资源审批）为基线，记录此后完成的前端修改。本批次不修改后端业务、权限、接口、数据库表结构或依赖版本。

### 1. 二次确认按钮文案统一

- 所有使用统一业务确认弹窗的地方，将取消按钮由“取消，暂不操作”改为“取消”。
- 项目、任务、预约、审批等原有二次确认仍保留；点击取消或关闭弹窗不会提交该次业务操作，也不会清空原表单。
- 确认按钮及审批、驳回、撤回等操作逻辑不变。
- 修改位置：`frontend/src/utils/confirm.ts`；同步更新[二次确认说明](SUBMISSION_CONFIRMATIONS.md)。

### 2. 隐藏全站可见滚动条

- 统一隐藏浏览器原生横向/纵向滚动条以及 Element Plus 自绘拖动滑块。
- 覆盖页面、侧边菜单、首页列表、表格、任务共享看板、弹窗、抽屉、下拉框等滚动区域，包括挂载到 `body` 的浮层。
- 保留原有可滚动内容及鼠标滚轮、触控板、触屏操作，没有通过禁用滚动来隐藏内容。
- 去掉首页今日日程、待办、健康度、关注、工时对比列表为滚动条预留的空隙。
- 宽表格和时间轴可用触控板横向手势，或浏览器支持的 `Shift + 鼠标滚轮` 浏览；预约条的拖动改期功能不受影响。
- 主要位置：`frontend/src/styles/index.css` 及相应首页列表组件。

### 3. 首页从四行精简为两排

#### 常驻内容

- 第一排继续保留四张统计卡片，顺序为：**待处理事项、进行中项目、任务完成率、需要关注**；统计口径和数据权限保持不变。
- 第二排左侧为**我的今日日程**，右侧为**项目进度**。常规宽屏下比例约为 1:3，日程列最低宽度 300px；两张卡片同高，随内容伸缩，最低 320px、最高 640px。
- 超出高度的内容在卡片内部滚轮浏览；窄窗口沿用响应式换列方式，不通过缩小字体压缩内容。
- 移除首页常驻的待处理面板、关注列表、项目健康度、计划与实际、工时趋势。日程不再位于原三列第二行，而是替换项目健康度，与项目进度并排展示。
- 相关统计数据和未展示组件源码保留，不删除项目、任务或执行记录。

#### 待处理事项右侧抽屉

- 点击顶部“待处理事项”卡片，从首页右侧打开列表窗口，宽度最高 640px；不跳转其他页面，不再滚动定位到原面板。
- 悬停统计卡片只显示简短说明，不自动展开待办列表；数量仍只显示一次，有待办时保留明显提醒。
- 抽屉提供“全部 / 审批与预约 / 我的任务”分类，展示原有权限范围内的待办和未完成任务摘要。
- 点击具体审批或预约继续打开原详情抽屉，支持原有确认、批准、驳回和二次确认流程。处理成功后关闭该详情，保留待办列表，并刷新顶部数量、待办内容和今日日程。
- 点击任务可打开任务详情；抽屉提供手动刷新、失败提示、空状态和已展示条数说明。原接口摘要数量限制不变，不将摘要冒充全量数据。
- 首页“需要关注”卡片继续可用，改为点击打开右侧关注列表，再查看具体异常详情；不常驻占用首页空间。
- 日程未确认预约的详情中，原“左侧待处理事项”指引改为顶部卡片/右侧窗口，并新增“查看待处理事项”快捷入口。

#### 保留的关联逻辑

- 今日日程继续使用北京时间、只展示当前登录用户的当天安排；待确认预约与已确定安排仍明确区分。
- 项目进度继续使用真实数据，保留原账号关联项目范围、展开/折叠、计划与实际时间条及任务详情入口，不因缩减布局减少项目数量。
- 审批对象、审批人、权限校验和后台通知流程均未改变。
- 新增组件：`frontend/src/components/dashboard/DashboardPendingDrawer.vue`。
- 调整入口：`frontend/src/views/dashboard/DashboardView.vue`；复用并调整概览、待办、日程、关注和详情抽屉组件。详细布局及自行查看清单见[首页办公屏幕适配说明](DASHBOARD_READABILITY.md)。

### 4. 任务名称居中与完整名称提示

- 任务管理表格的“任务名称”表头和名称内容居中对齐。
- 展开按钮左右采用对称预留空间，避免有子任务的行因按钮挤占而导致名称偏移；层级展开/折叠仍可正常操作。
- 长任务名称在表格中保持省略显示，不撑大列宽；鼠标悬停名称时，通过提示浮层展示完整文字，支持自动换行。
- 名称支持键盘焦点，展开按钮增加展开状态标识；不改变任务所属项目、成员、状态或编辑权限。
- 任务管理和项目详情中的“项目任务”共用组件，因此两处同步生效。
- 修改位置：`frontend/src/components/task/TaskManagementPanel.vue`。
