# 共享看板预约修复说明

## 本次修复

1. **成员选择顺序**：单人/批量预约按钮均按“项目 → 任务 → 指定成员 → 时间”填写。项目或任务改变时清空原人员选择，人员来自“有效项目成员 ∩ 当前任务指定成员 ∩ 当前账号可预约范围”。点击人员日程空白处的入口仍固定该人员，任务列表限定为分配给该人员的任务。
2. **任务周期提示**：选择任务后显示计划开始、计划结束、计划工时、本次可预约工时；日期控件禁止选择周期外日期，提交时前后端再次校验。原工作日/法定节假日/半小时粒度规则保持不变。
3. **本人撤回**：点击人员行“我的日程”或页头“我的项目预约”，从历史列表或预约详情撤回本人已确认、尚未开始的预约。项目须未结束，预约日期内不能已有该任务的本人普通执行记录（执行记录按天存储，因此保护同一天相关记录）。撤回后保留历史，释放时段与任务/项目额度并通知发起人。已开始/进行中/已完成预约不能撤回；他人不能代替被预约人撤回已确认预约。待确认预约仍由提交人或有全局预约管理权限者撤回，被预约人可拒绝。
4. **提交即预占工时**：任务预计工时是所有任务成员共享的总额度；待确认预约也预占。单人创建、批量创建、编辑、拖动改期、旧草稿提交、确认使用同一套任务/项目额度检查。批量按“单人工时 × 人数”一次校验，失败整批不保存。

## 时间占用与额度占用不是一回事

| 预约状态 | 预占任务/项目额度 | 独占人员时段 | 可见范围 |
| --- | --- | --- | --- |
| 待确认 / 变更待确认，尚未过结束时间 | 是 | 否 | 申请人与被预约人 |
| 已确认 / 进行中 | 是 | 是 | 原有日程查看权限范围 |
| 已完成 | 是，属于已使用工时 | 历史安排 | 原有日程查看权限范围 |
| 草稿 / 已拒绝 / 已撤回 / 已取消 | 否 | 否 | 保持原有历史记录权限 |
| 已过结束时间的待确认预约 | 否 | 否 | 生命周期同步后标记取消；不能再确认 |

不同项目经理仍可对同一人员的同一时段提交提案，前提是各自项目/任务额度足够。被预约人确认其中一条后，其他重叠提案关闭、释放预占额度并通知其申请人。撤回已确认预约不会自动恢复此前关闭的提案，需要重新申请。

例：任务 A 预计 **1h**，已提交 **1h 待确认预约**，则不能再为任何成员、任何时段额外预约该任务。可撤回原预约重新安排，或将总量拆为 **0.5h + 0.5h**。确认原预约不重复占用额度；编辑/改期排除原记录后按新工时重新计算。

`booked_hours` 和项目 `remaining_hours` 的口径已包含待确认预约。首页趋势等执行分析仍使用已确认的有效安排，不将待确认私有提案算作已落实工作计划。

## 数据与部署边界

- 本次不新增数据表、字段或迁移；在现有状态字段上计算额度，未直接修改任何数据库数据。
- 如果历史数据已经超额预约，不自动删除或拒绝它们。项目/任务剩余额度显示为 0，需由提交人撤回多余提案或通过既有流程调整工时后继续。
- 仓库前一项“加班与邮件通知”仍有其独立迁移要求，本说明不替代该功能部署文档。
- 仅进行了代码与文档编辑、静态阅读；未安装依赖、运行测试/构建、执行迁移或启动服务。

## 供自行验收的步骤

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 多任务不同成员 | 项目中任务 A 分给甲，任务 B 分给乙；批量预约先选 A 再切 B | A 只列甲，B 只列乙，原选择清空；快速切换也不回填旧结果 |
| 时间提示 | 选择任一任务，在周期外选日期或直接请求接口 | 表单显示起止日期；前后端拒绝周期外预约 |
| 未确认额度 | 1h 任务提交 1h 待确认，再提交另一个 1h 时段 | 第二次在提交阶段明确提示剩余额度不足，不生成记录 |
| 批量共享额度 | 1h 任务选择两位指定成员，各预约 1h | 提示整批需要 2h，整批失败；各预约 0.5h 可提交 |
| 同时提交 | 两个浏览器同时为同一 1h 任务各预约 1h | 最多一笔提交成功；另一笔返回额度不足，不超额 |
| 确认/改期 | 1h 待确认预约占满 1h 任务，再确认或等时长改期 | 不重复占用，不因为自身占用而报不足 |
| 私有提案 | 不同项目、各自额度足够的经理预约同一人同一时段 | 经理看不到对方待确认条目；被预约人可见多个提案；确认一条关闭其他提案并释放额度 |
| 撤回已确认 | 被预约人确认未来预约，然后从我的项目预约点击撤回 | 状态变为已撤回、看板隐藏、任务/项目额度释放，申请人收到通知 |
| 撤回保护 | 其他人尝试撤回已确认预约，或本人撤回已开始/有相关执行记录的预约 | 显示明确禁止原因，不改动记录 |
| 释放重约 | 拒绝/撤回待确认预约后刷新并重新预约 | 剩余额度恢复，可重新提交；保留历史说明 |
