# V2.0 前端

前端使用 Vue 3 Composition API、TypeScript、Vite、Vue Router、Pinia、Axios、Element Plus、Tailwind CSS 和 Day.js。V2.0 不新增图表依赖，驾驶舱和分析页使用原生 CSS 图形，避免扩大前端依赖面。

## V2 页面

- `views/dashboard`：管理驾驶舱、我的任务、被预约人预约待办，以及部门主管项目/资源审批。
- `views/schedule`：日/周/月共享看板、个人培训/会议/休假/出差安排与撤回、人员全部安排抽屉、时间点刻度、非工作时间及法定节假日配色、拖动和批量排期。
- `views/schedule/WorkCalendarView.vue`、`views/workload`、`views/risk`：源码保留，当前不注册 UI 路由。
- `views/notification`：站内通知、已读管理及右上角未读角标同步。
- `views/data-exchange`：Excel 模板、导入任务、错误明细和报表导出。
- `views/user`：维护员工号账号、姓名、邮箱、部门、组织、直属主管和系统角色。
- `views/role`：维护超级管理员、部门主管、职能主管、项目经理、项目成员五类系统角色的功能权限。

## 维护者执行

```powershell
npm install
npm run dev
```

维护者自行检查和构建：

```powershell
npm run type-check
npm run build
```

本次 V2.0 文件交付没有运行上述命令。

## 交互约定

- 登录表单统一填写员工号。新增用户时员工号只能由英文、数字和英文符号组成；姓名可使用任意语言，编辑时员工号不可修改。
- 用户编辑框只维护员工号、姓名、邮箱、部门、组织、直属主管和五类系统角色；密码重置与账号启停作为账号管理操作保留。
- 项目编号自动生成；所有项目和项目资源申请均由项目所属部门主管审批。追加工时、添加成员和移除成员在同一个资源申请弹窗提交，成员不再设置投入比例。
- 新建项目时必须按“部门 → 组织 → 启用人员”选择至少一名初始成员；项目经理自动成为固定成员。后续成员增删批准前不会改变项目成员表。
- “我的任务”直接展示在首页；任务支持任意层级。选择项目后显示项目计划周期，子任务只能选择父任务已有的项目成员。
- 所有登录用户都可从共享看板右上角或本人空白日程格进入“我的时间安排”，设置自己的培训、会议、休假、外出、出差或其他占用；只能管理和撤回本人创建的个人安排。
- 生效中的个人安排会按类型着色显示在日/周/月视图；保存前若与项目预约或其他个人安排重叠，会展示结构化冲突明细。撤回后对应时段重新开放。
- 日程预约按处理状态区分颜色：申请人与被预约人可看到待确认/变更待确认提案；无关人员只看到已确认/进行中/已完成安排。拒绝、撤回、取消和旧版草稿不占据日、周、月日程表。
- 新建预约按钮直接提交，不保存草稿；只有被预约人本人看到“本人同意/本人拒绝”，原提交人在确认前看到“撤回预约”。
- 普通任务项目成员可以为自己被分配的任务预约本人时间并自动确认，但不能预约其他人员；执行记录必须匹配一条已确认的本人任务预约。
- 预约表单按上午/下午提供半小时选项并自动计算工时，节假日与普通周末在日期控件中禁选，服务端仍会二次校验。
- 驾驶舱通过 `/schedules/my-pending` 只读取当前用户本人需要处理的预约；首页按钮调用本人确认/拒绝接口，不授予代批权限。
- 看板时间文字位于格线边界，每格代表相邻时间点之间的 30 分钟；工作日的 `08:00-08:30`、`12:00-13:00`、`17:30-18:00` 和普通周末使用灰色禁用背景，工作日历中的法定节假日整天使用红色系背景，调休工作日恢复正常工作时段颜色。
- 看板人员列是可点击入口；点击后使用独立的无日期、无项目过滤查询，在抽屉中按时间倒序分页展示当前权限范围内该人员的全部项目预约。
- 共享看板按项目、姓名、工号、部门、组织筛选并移除不匹配人员整行；项目经理看本人项目成员，部门主管看全部有效人员，职能主管看本人及全部层级下属，普通成员看本人。只有项目经理可使用本人负责且已审批的项目预约成员。
- 点击“预约人力”进入完整的项目/人员/任务/时间选择；点击人员空白格会自动带入并锁定该人员。
- 共享看板拖动排期时提交当前 `version`；服务端发现并发变更返回 `40903`，前端提示刷新。
- 待确认提案之间不构成排期冲突；被预约人确认一条后，其他同时间提案自动关闭。已确认项目预约与个人安排仍使用 `40901` 和结构化 `conflicts`。
- 文件下载使用 Blob；上传只接受 `.xlsx`。
- 通知中心只从右上角角标进入，左侧菜单不再重复展示。
- 通知角标和通知中心使用同一个 Pinia 状态；单条已读、全部已读或删除未读通知后会先即时更新，再向服务端复核未读总数。
